# mftecmd — salida sobre `nist-hacking-case.mft`

`mft.csv` es una **muestra representativa** (primeras ~2000 filas + todas las filas
notables: entradas borradas `InUse=false` y con ADS `HasAds=true`) del CSV completo de
**12.181 registros** que produjo MFTECmd. El artefacto completo (con su hash) queda en el
artifact store del caso (`artifacts/<run_id>/out/mft.csv`, run `e0e96164`).
