Ejecutores

Sin API keys. El modelo lo eliges tú.

Los prompts se ejecutan con el ejecutor que elijas. Los CLIs consumen tu propia suscripción a través de una sesión guardada en un volumen local del stack: ninguna clave de proveedor vive en el proyecto y las sesiones no salen de tu máquina.

Si eliges un ejecutor respaldado por la nube, Agentopsy lo advierte y lo registra. Sin ejecutor seleccionado no hay análisis — nunca un valor por defecto silencioso.

Instalación

Un solo comando.

El compose levanta la interfaz, el backend, el modelo local y los dos maletines forenses. Todos los puertos se publican únicamente en 127.0.0.1: nada queda expuesto fuera de tu máquina.

{{ r.n }} {{ r.text }}
# clona y levanta el stack
$ git clone https://github.com/Rorouh/Agentopsy.git
$ cd Agentopsy
$ docker compose up --build
# abre la interfaz
http://127.0.0.1:5173
En Apple Silicon los maletines se fijan a linux/amd64 y corren bajo emulación: funcionan igual, pero su build y sus análisis pesados van más lentos.

Tu evidencia no sale de tu máquina.

Clona el repositorio, levanta el compose y abre el navegador. Si quieres análisis 100 % local, elige Ollama y ni un byte cruza la red.
